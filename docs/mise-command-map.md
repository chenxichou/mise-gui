# Mise GUI — 命令与悬浮提示

悬浮卡片用于预览实际命令，或查看页面中可能被截断的完整路径。
不为按钮名称、简单说明、导航和纯文件操作增加悬浮提示。

## 展示规则

- 执行或查询 mise 的控件保留命令预览，使用实际工具名、版本、任务名和配置路径。
- 命令不翻译；复制图标与命令同行，复制后显示勾选状态。
- 配置、任务来源、安装目录及诊断/环境目录保留完整路径提示。
- 文档入口、侧边栏、窗口按钮、控制台展开、复制/打开目录、设置搜索不显示简单提示。
- 引入/移出配置、保存文件不执行 mise，不能显示“引入配置文件”“写入文件”等伪命令。
- 被动信息区域（例如“未启用”分组）不因其数据来自 mise 而显示命令卡片。
- 图标按钮保留 `aria-label`；不使用原生 `title`，避免重复弹出浏览器提示。

## 工具管理

工具页直接展示所有已安装和待安装版本，不提供“全部 / 已安装 / 待安装”筛选。
工具画布操作与“工具管理”标题合并为一行；查看文档、添加工具及画布操作使用图标按钮，保留可访问名称和实际命令预览。
画布底部提示栏与左侧设置栏使用相同高度，小窗口优先保留工具数量与连线图例。
工具页使用独立画布：拖动节点标题或顶部把手移动位置，拖动空白处平移，Ctrl/Command + 滚轮以指针位置缩放。
也可用缩放按钮、“适应画布”或“整理布局”；节点把手支持方向键微调，Shift 加速，Esc/失焦取消移动。
节点坐标和视图单独记在本机，不修改 mise 配置。适应模式会随节点新增/高度变化重新取景；手动视图保持用户的位置。
工具节点不展示配置来源或版本开关；已启用/待安装与配置的连线落到具体版本，
未启用版本按工具合并为一条工具节点连接。
配置节点左侧接实线（已启用），右侧接虚线（待安装为黄色，已停用为灰色）；同侧连接点沿节点边缘分布。
将已启用连线的配置端拖到同一配置右侧即可停用，执行 `mise unuse --no-prune`，保留安装文件及其他配置请求。
已停用虚线连接工具节点；拖回同一配置左侧即可恢复原版本请求（包含别名），保留同工具的其他版本。
停用请求记在桌面应用用户数据目录的 `disabled-connections.json`，重启后仍可恢复；安装文件和配置文件不依赖画布布局。
节点不显示“切换版本 / 连接工具 / 连接到配置”等文字按钮，使用圆点建立连接；管理已有请求时可点选连线使用操作栏。
也可将版本行左侧圆点拖到配置节点，直接预选该版本；工具节点底部圆点拖到配置节点后选择版本。
拖拽时预览连线并高亮可用落点，靠近画布边缘自动平移；松到空白处、Esc 或窗口失焦取消。
圆点支持键盘聚焦后按 Enter/空格，打开所选配置的连接窗口；拖拽不增加简单悬浮提示。
通过按钮、新建连线或跨配置移动端点打开的选择窗口会显示目标配置文件和版本变化，确认后才写入；同配置左右拖动直接停用/恢复。
已安装版本优先显示，远程列表不可用时仍可选择本机版本；未安装版本确认后先下载。
点击已有连线可选择它并显示两个端点和小型悬浮图标条，画布及节点不因选择而移位。
也可直接按住连线拖动，靠近工具的一半拖动工具端，靠近配置的一半拖动配置端；配置连接点无需预先选中即可抓取。
连线命中宽度为 20 像素，端点抓取区域保持 32 像素，不随画布缩小；拖动期间其他连线不拦截落点。
工具端拖到其他工具/版本，配置端拖到其他配置。
工具端落到具体版本行后直接执行改接，不打开选择窗口；落到工具节点时仍需选择版本。
直接改接沿用原配置文件及连接校验，执行期间禁用重复操作，失败后刷新并显示错误。
也可使用“更换版本 / 更换配置”；选中连线后按 Delete，或点击“删除连线”打开解除确认。
删除使用原配置中的版本写法（包含 `22`、`stable` 等别名），只删除所选配置请求，始终带 `--no-prune`。
跨配置或跨工具改接先写入新请求，再移除原请求；第二步失败会撤回目的文件的本次写入，
若目的文件已被外部修改则保留外部内容并报告错误。执行前重新核对原连接，拒绝过期或未管理的目标。
同一配置更换某个版本时保留同工具的其他版本请求；“未启用”连线来自安装状态，不提供删除操作。
连线及其命中区域高于节点内容，重叠后仍可选中；连接圆点、节点移动把手及安装/卸载操作保持可用。

## 命令输出

命令输出固定在工作区右侧，和左侧导航独立收起。收起后保留一条窄栏显示运行状态与输出行数，点击即可展开。
展开/收起偏好在本机记忆；命令和输出缓存不随面板收起中断或清空。小窗口下标题与行数分行显示，输出自动换行并纵向滚动。

## 工具操作命令

| 控件 | 命令预览 |
| --- | --- |
| 刷新 | `mise ls --json && mise ls --json --all-sources` |
| 添加工具 / 加载工具列表 | `mise registry --json` |
| 选择工具 / 加载版本列表 | `mise ls-remote <tool>` |
| 添加工具对话框 · 安装并设为当前 | `mise use <tool>@<version> --path "<selected-config>"` |
| 连接工具 / 切换版本 · 确认 | `mise use <tool>@<version> --path "<target-config>"` |
| 删除连线 · 确认 | `mise unuse <tool>@<requested-version> --no-prune --path "<source-config>"` |
| 跨配置/工具改接 · 确认 | `mise use <new-spec> --path "<target-config>" && mise unuse <old-spec> --no-prune --path "<source-config>"` |
| 仅安装 / 安装缺失版本 | `mise install <tool>@<version>` |
| 卸载入口 / 确认卸载 | `mise uninstall <tool>@<version>` |
| 导入已有安装 | `mise link <tool>@<version> "<path>"`，勾选覆盖时追加 `--force` |

安装并设为当前显式指定经过主进程校验的配置文件。仅安装不修改配置；
在配置编辑器移除工具请求会保留安装文件，并刷新工具连线。

## 配置、任务与诊断

| 控件 | 命令预览 |
| --- | --- |
| 配置刷新 | `mise config ls --tracked-configs && mise settings ls --all --json && mise settings ls --json` |
| 重新扫描配置列表 | `mise config ls --tracked-configs` |
| 信任配置 | `mise trust <path>` |
| 修改全局设置 | `mise settings set <key> <value>` |
| 恢复默认设置 | `mise settings unset <key>` |
| 任务刷新 | `mise tasks ls --json` |
| 运行任务 | `mise run <task>` |
| 诊断刷新 | `mise doctor --json` |
| mise 尚未安装时刷新 | `mise --version` |

配置读取/保存直接走文件系统和本地 TOML 校验，没有命令卡片；信任配置使用真实 mise 命令。
任务查询和运行均使用选中配置文件的目录。

## 实现与验证

`src/cmdtip.tsx` 提供命令预览、路径卡片和复制交互。
卡片根据窗口边界定位，鼠标移入命令卡片时保持可复制，离开后关闭；Escape、窗口失焦、
点击其他区域以及触发控件消失或禁用时关闭。键盘聚焦命令控件同样可预览。
弹窗底部按钮的命令卡片优先放在操作行上方，避免遮住取消/返回按钮。

`scripts/test-desktop.cjs` 检查命令复制、定位、关闭行为，以及简单控件没有悬浮提示。
`scripts/test-installed.cjs` 检查无筛选栏时的已安装/待安装版本展示及真实安装、卸载和重装流程。
`scripts/test-tool-graph.cjs` 用受控 IPC 测试实际 SVG 点击、两端拖拽、删除、键盘、取消、错误重试和无效目标。
`scripts/test-connections.ts` 检查改接顺序、失败撤回、外部编辑保护、过期请求、多版本保留和并发拒绝。
