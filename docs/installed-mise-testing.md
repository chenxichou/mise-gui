# 已安装 mise 的桌面功能回归

运行 `npm run test:installed`，先构建，再通过 Playwright 启动真实 Electron。
需要机器已经安装 mise、Node.js 位于 PATH，并能访问 mise 的 jq 下载源。

测试不安装或替换 mise 本身。工具查询、下载安装、连接、切换、卸载、重装和本机导入
均通过真实的 Electron IPC 与 mise 执行，使用 jq 1.7.1 和 1.8.1 作为下载测试对象。
还会通过项目任务执行 `jq --version`，检查版本切换后实际运行的版本。

每次运行创建独立的 Chromium 配置、应用偏好、mise 配置、数据、缓存、状态和 shims 目录。
任务夹具使用 Node 的绝对路径并关闭任务自动安装，避免继承用户 shell/shims 后安装无关运行时。
只替换测试实例的注册表读取结果，防止用户保存的目录覆盖测试隔离路径；禁止真实环境变量写入和安装 mise。
文件选择器由测试返回已知临时文件，其后的文件校验、导入和保存均走实际应用处理流程。
结束时清理本次临时目录，用户已安装工具、项目配置和用户环境变量不被修改。

覆盖内容：

- 自动识别真实 mise，诊断与实际目录校准。
- 中文及带空格路径的配置导入、TOML 校验、保存、信任。
- 任务成功、失败退出码、流式输出、收起后继续运行、重复操作禁用。
- 切换项目后的任务执行目录及任务环境变量。
- 全局设置保存和恢复默认。
- 工具搜索、远程版本查询、仅安装，通过添加工具写入/切换所选配置版本。
- 通过工具圆点连接和选择版本；预览精确命令和目标文件，取消不写入，更改其他配置不影响原项目。
- 版本圆点拖拽到配置，确认后执行真实版本切换；工具圆点拖拽后选择版本。
- 已有连线两端改接、只解除所选配置、保留安装文件与其他配置；真实别名和多版本请求切换/删除。
- 工具端落到明确版本后直接切换、不弹选择框；工具节点落点仍选择版本，直接切换失败保持原连接并释放控件。
- 空白落点、Esc、指针取消及失焦均取消拖拽；键盘连接、预选待安装版本和小窗口画布边缘自动平移。
- 离线仍可选择本机版本；连接失败保留选择并释放按钮，重复提交只运行一次。
- 通过配置编辑移除请求后保留安装文件，卸载取消/确认；待安装版本支持重装。
- 工具节点无来源和开关；已启用/待安装连到具体版本，多个未启用版本只连接工具一次。
- 本机已有安装导入、环境目录刷新、文档、小窗口布局及渲染进程重载。
- 已存在/尚未创建的全局配置精确写入；拒绝未管理的写入目标。
- 额外的图形数据夹具检查多工具、多版本、900/1180/1440 窗口缩放后的实际连线端点。

结果写入 `test-results/installed-mise-report.json`；截图位于同目录的 `installed-*.png`。
报告记录真实命令、完成的检查和失败时的界面/输出。网络不可用会导致下载安装检查失败。
离线与连接失败分支使用受控 IPC 错误响应；正常连接及切换均执行真实 mise 命令。

独立运行 `npm run test:graph` 可快速验证图形交互。该流程使用真实生产版 Electron 渲染器，
通过受控 IPC 数据检查点击连线、两端拖拽、跨工具改接、删除、无效落点、取消、重复提交和错误重试，禁止真实工具命令。
同时检查工具/配置节点移动、平移、指针锚定缩放、移动后连线跟随、取消恢复、布局重载记忆和整理布局。
新增连线覆盖节点时的点击检查，验证层级提升后仍可操作圆点；节点不含连接文字按钮。
检查配置左侧实线、右侧虚线的端点坐标，以及拖动两端时固定点和落点预览所在侧。
覆盖连接点边框外沿的左右落点；同一配置右移停用、虚线连接工具节点、重新加载后左移恢复。真实 mise 校验别名和多版本请求保留、安装目录不被删除、其他配置不被改写；后端检查失败后保留原连接并支持重试。
选择连线不改变画布尺寸/视图；小型悬浮图标条、缩放后的端点抓取范围、无需预选直接拖线及配置连接点均有交互检查。
命令面板检查验证右侧布局、独立收起、重载记忆和左侧导航折叠；任务回归检查收起期间命令继续输出。
`npm test` 中的连接事务检查覆盖新请求失败、旧请求移除失败时撤回、外部修改不被覆盖及并发保护。
画布几何检查覆盖缩放范围、负坐标取景、节点不重叠及固定位置保留。
额外覆盖工具列表 IPC 拒绝后的显式重试、任务 IPC 拒绝后忙碌状态释放与错误输出；生产构建校验独立检查模拟数据不会进入正式资源。

此流程重现并覆盖三个实际缺陷：版本开关曾捕获旧的配置选择，导致写入默认工作目录；
工具列表曾只补充已知版本的来源，漏掉其他项目引用但未安装的版本，导致卸载后不能在页面重装；
全局配置仅依赖工作目录定位会写入其他文件，现对启用/停用显式传递经过校验的 `--path`。
